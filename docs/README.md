# Safety Notes

This project is an educational AI agent prototype. It is not intended for production use.

## Potential Risks

- **Shell Execution:** The `run_command` tool can execute shell commands with the permissions of the current runtime.
- **File Access:** File operations may access files outside the intended project directory if path restrictions are not implemented.
- **Model-generated Commands:** Tool calls generated by the language model should always be treated as untrusted input.
- **Approval Limitations:** User confirmation is a basic safety measure, not a secure sandbox.

## Recommended Precautions

1. Run the notebook in a temporary Google Colab runtime or disposable virtual machine.
2. Review every shell command before approving it.
3. Avoid mounting Google Drive folders containing sensitive information.
4. Never expose API keys, passwords, or access tokens in the notebook.
5. Do not commit `.env` files or credentials to GitHub.
6. Implement path validation and stronger execution isolation before using the agent with important files.

## Disclaimer

The developer is not responsible for damage caused by executing untrusted commands or running the prototype in an unsafe environment.
